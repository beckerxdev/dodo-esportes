# Dodô Esportes

Projeto de desenvolvimento de um site para uma loja de artigos esportivos, com vitrine de produtos e painel administrativo.

### Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- Supabase

### Funcionalidades
- Vitrine de produtos
- Organização por categorias
- Painel administrativo
- Gerenciamento de produtos e imagens
- Configurações de contato e redes sociais
- Integração com banco de dados

### Estrutura
O projeto possui uma interface pública para visitantes e uma área administrativa para gerenciamento do conteúdo da loja.
